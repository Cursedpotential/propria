Source precedence: current explicit owner instructions; recovered earlier owner decisions; verified current source/runtime receipts; original handoffs; later assistant interpretations; donor ideas. Current code establishes implementation, not product intent. Evidence details and remaining checks are recorded in the input reports rather than repeated throughout the interface.

This delivery adds planning/review artifacts and bounded archive inspection. Application migration, deployment and content import are future phases. Existing product code and concurrent changes remain with their owners. Docstore is accessible through its existing CLI; the publication receipt records document capture/registration and readback separately from search-index freshness. These documents remain in the canonical application's directory.
