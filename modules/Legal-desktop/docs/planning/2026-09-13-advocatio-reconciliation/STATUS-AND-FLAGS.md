# Quiet, useful status cues

The owner wants dense readable work, with compact flags where attention is needed. No repeated legal disclaimers, giant warning blocks or automatic cautionary footer on every page, note, translation or agent answer.

## Proposed presentation

| Situation | Visible cue | Detail on click/tap or keyboard activation |
|---|---|---|
| No supporting source | Small `Missing source` flag beside the claim | Which proposition lacks a source; link to investigation/search task. |
| Source linked, relationship not checked | `Support review pending` | Exact source span and review criterion. |
| Only part of a statement is supported | `Partial support` | Highlight supported versus unsupported clauses. |
| Conflicting evidence | `Conflicting sources` | Side-by-side source links and review notes. |
| Citation/currentness incomplete | `Citation check pending` or `Source date needed` | Missing field/check and the linked authority version. |
| Method/structure finding | Small finding count | Specific passage and unmet criterion, with suggested change. |
| Substantive review remains | `Legal review pending` in the review panel | Reviewer, scope and unresolved reasoning/relief issues. |
| Source or document changed | `Review outdated` | Previous versus current version and checks affected. |
| AI analysis or personal note | Ordinary type label in metadata | Original source/method/provenance when opened; no paragraph-long repeated warning. |
| Save/conversion failed | Inline actionable error near the operation | What failed, whether the original is saved and the available retry/recovery action. |

Avoid a generic green 'validated' badge. A compact review strip can show **Structure · Citations · Support · Legal review**, with a status for each and details on demand. It should fit the work rather than compete with it.

Information is available through mouse, keyboard and touch. Use text or accessible labels as well as color. Preserve all review/provenance detail in records; simplify its default presentation.

Generated drafts, translations and firm messages follow the same rule: put unresolved issues in linked review findings/flags, not an unsolicited disclaimer appended to the content. Blocking an actual invalid operation should be specific to that operation, with a way forward.

Acceptance fixture: a page with ten mixed-status notes shows ten readable notes and only applicable compact cues, zero repeated disclaimer paragraphs, and a reachable details inspector for every cue.
