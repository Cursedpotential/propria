Start with a purpose: what fact does the exhibit tend to prove? Then identify witness knowledge, source, chain/preservation, accurate-copy basis, and a hearsay path. Authentication is not the same as hearsay, relevance, or privilege. [source: michigan-mre-guide | pin: MRE 901]

For electronic material, retain the original/native file when lawfully available, describe how the copy was made, identify account/device ownership only from lawful knowledge, and use distinctive characteristics cautiously. [source: michigan-mre-guide | pin: MRE 901; MRE 1001]

Hearsay analysis asks whether an out-of-court statement is offered for its truth and, if so, whether an exclusion or exception applies. A child’s statement, medical record, police report, or screenshot may trigger separate rules and privileges. [source: michigan-mre-guide | pin: MRE 801–807]

The post-restyling labels in the current official MRE control. Old secondary labels are cross-reference aids only; recheck current numbering before a hearing. [source: michigan-mre-guide | pin: MRE 901/902]

**Your case is different if…** the evidence was obtained through an account/device not clearly authorized, contains a child’s report, or requires a custodian/subpoena.
