# Component Library Options

> Static starting hypothesis only. Claude must verify/supplement via live search_web research per SKILL.md Step 1.

- shadcn/ui + termcn: Tailwind-based, terminal-styled, closest match to Bloomberg aesthetic.
- Blueprint (Palantir): dense data-grid primitives, strong tables/panels, more "enterprise" look by default.
- Chakra UI: accessible, fast, generic SaaS look without heavy re-theming.
- AdminLTE/Flowbite dark templates: good for rapid dashboard prototyping/reference, not a long-term foundation.
