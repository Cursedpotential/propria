# Fallback Decision Matrix

Use this only when the task does not map cleanly to one of the eight model families or six fixed workflows. The purpose is to identify the missing reasoning capability, not to force a category.

| Dominant need | Start with | Supporting lenses when material |
|---|---|---|
| Establish what is true | reason | forecast for uncertainty; debias for interpretation risk |
| Find why something happened | diagnose | systems when causes interact; reason for hypothesis testing |
| Understand interactions or blast radius | systems | incentives for behavior; decide for intervention risk |
| Choose among actions | decide | incentives for downstream effects; forecast for probabilities |
| Predict an outcome/quantity | forecast | reason for assumptions; systems for interacting drivers |
| Understand behavior/reaction | incentives | systems for feedback; debias for attribution risk |
| Form coherent direction | strategy | systems for constraints; decide for irreversible commitments |
| Check whether the current read is distorted | debias | reason for claims/evidence; forecast for base rates |

## No clean fit

1. State the actual question in one sentence.
2. Identify what kind of uncertainty is blocking progress: factual, causal, systemic, behavioral, probabilistic, decisional, strategic, or interpretive.
3. Select the smallest model set that addresses those uncertainties.
4. Assign each model a role and depth before loading it.
5. If no existing model addresses the missing capability, continue with ordinary reasoning and report the gap as a candidate future skill; do not invent a permanent rule or silently repurpose an unrelated model.
