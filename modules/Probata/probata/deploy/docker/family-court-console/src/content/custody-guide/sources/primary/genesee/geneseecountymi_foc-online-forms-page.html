Online Forms

Friend of the Court forms can be submitted via mail to 630 S. Saginaw Street, Suite 2500, Flint, MI  48502, (fax) 810-257-3244, or via email to [email protected].  Many forms can also be submitted electronically by logging in to your MiChildSupport account.  If you haven't registered for a MiChildSupport account, you can do that here.

For videos on how to fill out some of the forms below, click here.

Revocation of Paternity - DNA Testing6 documents

  • Application to Remove or Replace Father on a Birth Record
    document Header Application to Remove or Replace Father on a Birth Record
    This document needs to be sent to the State of Michigan vital records. 
  • Motion and Order to Determine Child Born Out of Wedlock
    document Header Motion and Order to Determine Child Born Out of Wedlock
    This motion packet is for when a legal father is established by marriage and a party wants to determine that someone else is the father.  This is for if the parties already have a case to file the motion into.
  • Motion and Order to Revoke Order of Filiation
    document Header Motion and Order to Revoke Order of Filiation
    This packet is for when an order has been entered to establish paternity and a party wants DNA testing to set aside that order.
  • Motion and Order to Set Aside Affidavit of Parentage
    document Header Motion and Order to Set Aside Affidavit of Parentage
    This motion packet is for when an affidavit of parentage was signed and a party wants to set aside the affidavit of parentage.  This packet is for if the parties have an existing case to file into.
  • New Case and Motion to Determine Child Born Out of Wedlock
    document Header New Case and Motion to Determine Child Born Out of Wedlock
    This motion packet is for when a legal father is established by marriage and the parties do not have an existing case to file the motion into. 
  • New Case and Motion to Set Aside Affidavit of Parentage
    document Header New Case and Motion to Set Aside Affidavit of Parentage
    This motion packet is for when an affidavit of parentage was signed to make a legal father and a party wants to set aside that affidavit.  This packet is for when the parties don't have a case with the court yet and need to start a new case.

PARENTING TIME PLANS6 documents

  • Alternate Weekend Parenting Time
    document Header Alternate Weekend Parenting Time
    A parenting time plan for families who want an alternate weekend type schedule, but want an updated parenting time plan from the old reasonable parenting time plan.
  • Joint Parenting Time Plan Split Week
    document Header Joint Parenting Time Plan Split Week
    A parenting time plan for equal parenting time for each parent.  This parenting time plan involves splitting each week, which involves more exchanges, but less time in between parenting time.
  • Joint Parenting Time Plan Week On Week Off
    document Header Joint Parenting Time Plan Week On Week Off
    A parenting time plan for equal parenting time for each parent.  This plan is a week on week off schedule. 
  • New Family Parenting Time Plan Under Age 2
    document Header New Family Parenting Time Plan Under Age 2
    A parenting time plan for new families with young child(ren).  Provides more frequent visits for shorter durations while the child is younger.
  • Reasonable Parenting Time Rights
    document Header Reasonable Parenting Time Rights
    A parenting time plan for families who have an order that provides for reasonable rights of parenting time.
  • Transitional Parenting Time Plan
    document Header Transitional Parenting Time Plan
    A parenting time plan for when one parent has not had contact with the minor child(ren) for some time.
