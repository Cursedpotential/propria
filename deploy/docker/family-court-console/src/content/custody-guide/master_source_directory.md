# Michigan Pro Se Custody Guide — Master Source Directory

This is the consolidated source directory for the Michigan pro se custody guide project (Genesee County), compiled from the research compendium, master outline v2, and the three model-council reports. Links were verified as extracted on August 9, 2026; time-sensitive items, including fees, contacts, and form revisions, must be re-verified before publication. This directory organizes the extracted citations only and does not independently assess the current contents of the linked pages.
