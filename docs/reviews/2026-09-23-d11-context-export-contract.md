## Implemented contract

`ContextExportManifest` pins export ID/version/predecessor digest, matter, creator/purpose/audience, generator/template/redaction-profile versions, output kind, snapshot and as-lived cutoff or hindsight mode, approved route ID/map version/binding, fresh versioned destination, selected entry IDs, source IDs/versions/locators/content-hash observations/status/availability, entry record IDs/versions/claim-source relations/origin/privacy/time text/precision/basis/review/evidence-status snapshot, explicit requested source copies, member digests, offline member links, and unavailable/excluded source IDs. It returns a deterministic canonical SHA-256 digest for an identical manifest and route binding. Frozen dataclasses and tuple validation prevent ordinary accidental mutation of the package shape. It creates **no** canonical event, source, evidence identity, or second corpus.

The validator rejects mismatched matter/kind/route version/effective time, noncanonical or encoded traversal paths, wrong versioned destination, omitted or extra selected entries, unrequested/missing source copies, absent offline-link targets, duplicate IDs/paths, invalid hashes/versions, future sources in an as-lived selection, and private-strategy-labelled entries in internal/external audiences. Non-available sources must be visibly excluded and cannot be copied. Its only release state is `prepared_unreleased`; this never means legal adoption, approval, release, filing, service, or evidence promotion. A package can represent a pre-promotion context narrative.
