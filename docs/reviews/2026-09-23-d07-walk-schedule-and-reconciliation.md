## Bounded executable slice

`server/evidence/derivation.py` now validates all bounded walk cutoffs before opening the writer transaction: every value must be an aware datetime, cutoffs must strictly advance after UTC normalization, custom steps must stay within the explicit ceiling, and hindsight cannot carry a hidden bounded schedule. The previous custom behavior silently replaced an over-ceiling cutoff with the ceiling. Rejecting that request preserves what the caller asked for and prevents a misleading saved step. `tests/test_derivation_temporal_contract.py` covers offset-equivalent chronology, naive/decreasing/duplicate cutoffs, over-ceiling and hindsight misuse, with invalid cases reaching no database operation. The sole-writer, snapshot, slice query, hashes and audit path remain the existing implementation.

Input: `derive_walk(case_id, agent_id, horizon_policy, horizon_schedule, custom_horizon_ceiling, ...)`. Output for valid input remains the persisted `walk_run.id` and its step/chain/audit receipts. Invalid input raises `ValueError` before `_with_conn`. It does not truncate, silently clamp, substitute current time, or produce a partial run. UTC normalization is limited to scheduling; raw source clocks and uncertainty are not rewritten.
