## 0. Executive finding
The investigated record does **not** establish that the historical AI chat was lost. It establishes that exact historical identifiers produced **zero matches in two named Weaviate collections** in an earlier bounded live readback; no native import mapping was verified. There is an important distinction between **not indexed under these identifiers**, **not locatable through this reader**, **not ingested through a native workflow**, and **original content absent**. Only the bounded first two observations are supported.

The **controlling 2026-10-15 owner correction** is that AI chat **content goes directly to Weaviate, not PostgreSQL**. PostgreSQL holds extracted AI events, timelines, entities, artifacts, plus governance and provenance/control metadata. Older documentation that places AI chat bodies in PostgreSQL is superseded for this lane. Missing historical PG normalized generation rows are **not** an authorization to reconstruct them. Original objects and their source/version provenance must be preserved.

Read-only live/browser checks and isolated transactional fixture tests documented on October 15 have resolved several earlier UI problems, but full Temporal-through-browser mutation testing and real screen-reader acceptance remain unproven. Five case media samples are malformed **at the retrieved-byte level**; their provenance and availability of earlier good versions remain unknown. The legacy durable-mode block is a required safeguard.

## 7. Dependencies and regression hazards

2. Weaviate collection schema, field tokenization, vector names, source-version array membership, alias structure and current deployment config must be verified before interpreting “0”.
3. Original object identifiers, version IDs, ETags and hashes must be pinned; MIME/label repairs do not restore malformed bytes. A new recovered version must not replace or delete the previously retained byte sequence.

5. Unknown activity receipts, missing workflow history, and absence of output groups each carry different state. Keep “not queried,” “partial,” “missing,” “zero,” and “failed” separate.
6. A UI repair grants no approval to reprocess, classify, modify global aliases, evidence-promote, or assign a historical operating mode.
