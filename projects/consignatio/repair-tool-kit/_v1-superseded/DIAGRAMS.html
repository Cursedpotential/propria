4 · Why no primary engine

Seven readers, same file, same line. The obvious pick was the worst, and that was not knowable from documentation.

ReaderLangOutputCodepointGlyphsVerdict

Why mutool is different. n is the literal content-stream byte — wrong but reversible. I corresponds to nothing and is indistinguishable from a real capital I in running text.

6 · XML two-stage ingestion

DuckDB is the query engine, but it cannot be pointed at the raw file. Two limits force a pre-pass.

flowchart TB
  A["source.xml
3,852,198 B"] --> B["slim pass · lxml"]
  B --> C["blobs/<sha256>
8 files · 2,822,412 B"]
  B --> D["slim.xml
89,925 B"]
  B -.-> N["set data_sha256 on
ALL parts, even empty"]
  D --> E["DuckDB read_xml"]
  E --> F["messages · 231"]
  E --> G["mms_parts · 14"]
  E --> H["mms_addrs · 12"]
  F & G & H --> I["Parquet"]
S-1 · Sparse attributes vanish. Only 8 of 14 parts had data=. DuckDB's sample-based inference omitted the field entirely and every image disappeared with no warning. sample_size=-1 does not help. Setting the attribute on every element does.
S-3 · XPath functions OOM. xml_extract_attributes(xml,'//sms') consumed 3.1 GiB on a 3.8 MB file. Never use them for bulk work.

11 · Decisions and reversals

DecisionStatusWhy
Go orchestratorlockedtsnet is Go-native; dual-platform static builds; COM advantage for Rust evaporated when v1 chose a registry cascade
Subprocess engines, JSON contractlockedno language lock-in; the winning reader was not predictable
Extract always, repair on requestlockedextraction is non-destructive, so it needs no justification
Profile → route → one engine → checklockedconsensus on every file does not pay for itself
DuckDB + slim pre-pass for XMLlockedverified on the real export; neither half works alone
mutool as primary text enginereversedchosen on reputation for a bbox requirement that did not exist; worst of seven on the first real file
Rust orchestratorreversedonly advantage was COM, which v1 does not use
Consensus on every filecutover-engineering (R2, R5)
Calibration framework, fidelity vectorscutMatt inspects output directly; a hand-edited table suffices
Per-file RFC 3161 timestampsdeferredabove the bar set by R2
